# 整頓⑨ 長い CSS の分割 計画(下書き・2026-10-27)

## 対象
housing.css 11216 / military.css 1996 / index.css 1478 / MitigationSheet.css 1001 → 各 500 行以下。

## 方式(順番を一切変えない)
- 元のファイルは「入口」として残し、中身は `@import "./housing/01-xxx.css";` の並びだけにする。
  読み込み側(HousingShell ほか 4 か所・MitigationSheet.tsx・main の index.css)は変更不要。
- 分割は既存の見出しコメント(housing.css は 87 区切り)の境目で、上から順に連番ファイルへ。中身は一字一句そのまま。
- index.css は Tailwind v4(`@import "tailwindcss"`・`@theme`・`@layer base/components`)。`@theme` と先頭の `@import "tailwindcss"` は入口に残し、
  `@layer` の中身は `@layer components { … }` ごと分割先へ(同名 @layer は複数あっても合流する)。

## 機械判定(合格条件)
1. **ビルド後の CSS が完全一致**: 分割前後で `npm run build` → `dist/assets/*.css` を整形なしで比較し差分 0(順番が保たれていれば同一になる)。
2. 行の突き合わせ: 分割前の全行 = 分割後の全ファイルの連結(@import 行を除く)。
3. visual-regress --compare=dpr2 全 323 一致。
