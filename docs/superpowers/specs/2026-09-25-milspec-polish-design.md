## 1. 画面の層構造(奥 → 手前)

| 層 | 中身 |
|---|---|
| L1 背景動画 | 機械の壁動画(銅配線と歯車)。暗く・彩度控えめ。**ダーク/ライト共通で暗いまま**。 |
| L2 フレーム | パネルを支える梁。パネル間に数 px の**隙間**を作り、そこから L1 が覗く。隙間の縁は面取りで板の厚みを見せる。 |
| L3 装甲パネル | 主役。§2 の形の言語で作る。 |
| L4 配線と光 | 継ぎ目・隙間に沿う細い配線(SVG)。光のパルスが流れる(§4)。 |
| L5 操作部品 | 機械仕掛けのスイッチ(§3)とタービン(既存 `useTurbineCluster`・残す)。 |

**画面幅への畳み方**: 要素を「操作」と「飾り」に分け、幅が足りなくなったら飾りから優先度順に非表示にする。操作部品は絶対に隠さない。飾りの優先度は実装計画で要素ごとに決める。

**サイズ感**: 見た目優先で攻めた小ささにする。飾り文字(ステンシル・部品番号)は最小クラス、スイッチのラベルは小さめ、**表の中身(時間・攻撃名・ダメージ)は今の可読性を維持**する。

## 2. 装甲パネルの形の言語(MGEX ユニコーン × Nothing)

基本は材料言語 doc の 9 原則(メリハリ / 説明可能性 / やりすぎない / 光は上から / 外周の面取り / スジボリ / 墨入れ / デカール / 傷は摩耗部だけ)を守る。そのうえで「四角の連続」を壊すために次を使う。

- **角の落とし方をパネルごとに変える**: C 面(斜め)/ 段付き / 片側だけ大きく落とす。同じ形を隣に並べない。
- **一辺だけの段差・一部だけの沈み込み**: パネルの一部が一段下がっている、ハッチの蓋のように分割されている。
- **スジボリはクランクで繋ぐ**: 一周させず、途中で折れて隣の線や隙間に合流させる。溝は「明縁→暗芯→明縁」。
- **密度勾配**: ヘッダー・操作盤・継ぎ目は細かく、広い面は無地で残す。
- **Nothing の要素**: ドットマトリクス風の文字を飾りラベルの一部に使う / 光は細い帯で継ぎ目に沿わせる(Glyph 的)/ 色は 1 点だけ。
- **禁止**(過去の不採用から): ランダム散布の傷・ノイズ / 面全体の発光 / ガラス窓や画面の新設 / 全パネル同じ長方形。

## 3. 色

| | ライト(白装甲) | ダーク(ガンメタル装甲) |
|---|---|---|
| 装甲パネル | オフホワイト | 暗い鉄色 |
| フレーム | 濃いグレー | 黒 |
| 文字 | 黒系 | 白〜グレー |
| 隙間の奥 | 暗い機械の壁動画 | 同左 |
| 光る色 | **赤(1 色のみ)** | **赤(1 色のみ)** |

- 下地は白・グレー・黒だけ。赤は「配線を走る光」「点灯ランプ」「スイッチの ON 表示」にだけ使う。
- 形と質感は両モード共通で、変わるのは色の値だけにする(`.theme-military.theme-dark` / `.theme-military.theme-light` でトークンだけを差し替える)。
- **表の意味色は維持**: 軽減後ダメージの緑など。**致死警告**は飾りの赤と混ざらないよう、色に加えて斜線模様の形でも区別する。**表示は致死になる攻撃の段だけ**(同じ秒に攻撃が複数ある行でも行全体を赤くしない)。表の中なので点滅はしない(§6)。(2026-10-21 masaya 一任で確定)

## 4. 配線と光

- 配線は手で置いた決まった経路だけにする(隙間・継ぎ目・スイッチからパネルへ)。ランダム生成しない。
- 光の手法: SVG の `stroke-dasharray` / `stroke-dashoffset` を動かして光のパルスが線上を流れる(参考 = uiverse `dexter-st/giant-newt-48` の dash アニメ)。発光は `drop-shadow` を線 1 本単位に限定する。
- **光は意味のある時に走る**: スイッチ操作時は、そのスイッチから出る配線を 1 回光が走る。
- **常時**: 十数秒に 1 本、決まった順番の経路をゆっくり流れる程度にする。同時に光る本数に上限を設ける。

## 5. 背景動画とコスト対策

**素材**: masaya 提供の 1280×720 / 24fps / 10 秒 / 3.1MB の mp4。音声を除去し、暗め・彩度控えめに再エンコードする(試算 0.2〜0.4MB)。webm 版と poster 静止画(webp)も作る。10 秒ループのつなぎ目は見本の段階で確認し、目立つ場合はクロスフェード版を作る。

**ハウジング背景動画の対策を全部引き継ぐ**(`src/components/housing/workspace/SceneryVideo.tsx` / `vercel.json`)
1. 長期キャッシュ + Cloudflare 前段で配信し、Vercel まで来させない
2. webm → mp4 の順で `<source>` を並べる
3. poster 静止画で即表示し、失敗時も静止画で代用する
4. 使っていない動画は先読みしない(`preload`)
5. `prefers-reduced-motion` で停止する
6. 読込失敗時の再試行は 1 回まで

**MIL-SPEC で追加する対策**
7. **標準テーマでは動画要素そのものを生成しない**(ダウンロード 0)
8. スマホ幅では動画を使わず poster のみ
9. 動画ファイルは Vite の import で `/assets/`(ハッシュ付きファイル名)に出す → 既存の `vercel.json` `/assets/(.*)` = `max-age=31536000, immutable` と Cloudflare の static キャッシュルールにそのまま乗る。中身を変えればファイル名が変わるので、古いキャッシュ事故が起きない
10. タブ非表示(`visibilitychange`)で一時停止

**デプロイ後の確認**: `curl -I` で Cloudflare の HIT を確認する。Range 付きリクエストで先頭が正しく返ること(シーク・ループが壊れないこと)も確認する。

## 6. 性能

- アニメーションは `transform` / `opacity` / `stroke-dashoffset` のみで作る。レイアウトを動かすプロパティはアニメしない。
- 背景動画の上に `backdrop-filter`(すりガラス)を重ねない。
- タイムライン表の中(行・セル)には、常時動くアニメを置かない。
- 表の行・セル・段ごとに付く効果を増やさない: ぼかし付きの影・行ごとの疑似要素・`:has()`。既存の行のぼかし影(military.css の `[data-time-row]` 3 層)はぼかし無しの線に置き換える(行は 1000 を超え得る)。
- 表の行は「1 段 = 攻撃 1 つ・高さ 25px(PC)× 攻撃数」(2026-09-28 本番の行の作り)。見本・検証は 1/2/3 段の混在行で行う。マウスを乗せたときは行全体が光る(今のまま・2026-10-21 確定)。ゼブラ・4 行ごとの溝も今のまま。
- 変更前後で、同じ fixture を縦スクロールしたときのフレーム時間を Playwright で計測・比較する(劣化したら差し戻す)。

## 7. 機械仕掛けのスイッチ(masaya 承認済みの割り当て)

共通の動き: **速く・重く・最後にガチッ**(止まる瞬間に小さく反動)。ふわっとしたイージングは使わない。

| 操作の種類 | 部品 | 動き | 対象の例 |
|---|---|---|---|
| ON/OFF | スライドパネル | 装甲の板が横に滑り、下から赤ランプが出る。配線に光が走る | 表の展開 / メモ / リキャスト行 / ライトパーティ表示 |
| 押して開く | 深く沈む押しボタン | 押している間は奥まで沈み影が消える。離すと戻る | パーティ編成 / インポート / チュートリアル / 新規作成 |
| 1 つ選ぶ | ロータリー | 目印が段ごとにカチッと止まりながら回る | 零式 / 絶 / その他 / アーカイブ |
| 危ない操作 | カバー付き | 1 回目でカバーが開き、2 回目で押せる。押さなければ数秒で自動で閉じる | 削除系 |
| 標準⇄軍事 | 両手の大レバー | ドラッグまたはクリックで下ろす → §8 の演出 | テーマ切替(`MilspecStyleToggle` の置き換え) |

- 対象の全件割り当ては実装計画で一覧化する(ここに無いボタンも同じ規則で分類する)。
- 見た目は変えても、既存のボタンの `aria-label` / `aria-pressed` / キーボード操作(Enter / Space)/ フォーカス表示は維持する。カバー付きは、キーボードでも「開く → 押す」の 2 段で操作できるようにする。

## 8. 電源投入の演出(大レバー)

レバーを下ろしきると、約 1 秒で次を順に流す。**毎回流す**(masaya 承認済み)。
1. 画面が一瞬落ちる
2. パネルが順番に点灯する
3. 配線を光が駆け抜ける
4. タービンが回り始め、回転数が上がる

軍事 → 標準へ戻すときは、短い電源断の演出(0.3 秒程度)だけにする。`prefers-reduced-motion` のときは演出なしで即時に切り替える。
